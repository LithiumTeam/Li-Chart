# Li-Chart

<p>A small chart rendering engine under development for rendering csv files via pandas python module.</p>
<p>Use this engine for editing csv/excel data and make it cleaner + asking ai for helping!</p>

# Usage
<a href="/Images">See Some Images From App</a>
<p>Easily open a new .csv file then edit, fill blank data, use ai to edit or anything for your data and more.</p>

# Nice points
<ul>
  <ui>Ai can edit your data by your premission.</ui>
  <ui>Can fill blank data (if it is number use median else 'Empty' will fill that).</ui>
  <ui>Can use pandas functions in a sample python code editor.</ui>
</ul>
